# ☁ CloudNotes – Educational Resource Hub

## Project Overview

**CloudNotes** is a single-page educational resource hub designed to provide students and learners with an accessible and organized platform for exploring educational materials.

The website features different subject categories, sample learning resources, and information about the platform. It aims to make discovering and accessing educational content simple and convenient.

## Features

- **Navigation Bar** – Provides easy navigation between the Home, Categories, and About sections.
- **Home Section** – Introduces CloudNotes and highlights featured educational resources.
- **Categories Section** – Displays different educational subjects, including Mathematics, Science, and History.
- **Sample Resources** – Showcases sample educational materials and study guides.
- **About Section** – Presents the platform's mission and contact information.
- **Responsive Design** – Adapts the website layout to desktop, tablet, and mobile screens.
- **Footer** – Displays website information, quick navigation links, and copyright details.

## Installation and Usage

1. Clone or download the project repository.
2. Open the `CloudNotes` project folder.
3. Open `index.html` in your preferred web browser.
4. Explore the different sections using the navigation bar.

**Note:** Bootstrap 5.0.2 is included through a CDN, so an internet connection is required to load the Bootstrap resources.

## Project Purpose

CloudNotes was developed as part of a Mock Technical Exam focused on application building. The project demonstrates the use of HTML, CSS, Bootstrap, and basic JavaScript integration in developing a responsive, single-page educational resource hub.
